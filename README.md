# Google Play publishing kit

Materials updated on August 8, 2026, for Liftbook's first release:

- `index.html`: Vite entry point for the responsive Liftbook landing page.
- `src/`: React + TypeScript application containing the components, pages, and
  shared visual system for the landing page and privacy policy.
- `privacy-policy/index.html`: independent Vite entry point that preserves the
  public `/privacy-policy/` URL on static hosting.
- `en-US/`: store title, descriptions, and release notes.
- `store-icon.png`: 512 × 512 32-bit PNG icon synchronized with the app's
  current visual identity.
- `feature-graphic.svg`: editable source for the feature graphic.
- `feature-graphic.png`: 1024 × 500 24-bit PNG feature graphic without
  transparency.
- `feature-graphic-alt.txt`: alternative text for the feature graphic.
- `screenshots/`: four real 1080 × 1920 phone screenshots, ready for upload in
  numerical order.
- `screenshots-alt.txt`: alternative text for the screenshots.
- `src/pages/PrivacyPolicyPage.tsx`: detailed English privacy policy for the
  Android app, covering the app/developer identity, contact details, personal
  and sensitive data, permissions, user-directed transfers, security,
  retention, deletion, website hosting, and the health disclaimer.
- `data-safety.md`: proposed answers for Data safety and the health declaration.
- `play-console-checklist.md`: status of the items that depend on Google Play
  Console.

The public support email used in the privacy policy is
`liftbook.support@gmail.com`, the same value as the app's `SUPPORT_EMAIL`.
Because this policy is static HTML, keep both copies synchronized when changing
the address.

The developer is identified in the policy as `rabpaulodev`, matching the owner
in `app.json`. Before publishing, replace this text with the exact public name
of the verified Google Play Console account if it is different.

## Site development and publishing

Requirements: Node.js 20.19+ or 22.12+ and npm.

```bash
npm install
npm run dev
```

Before publishing, generate and validate the production build:

```bash
npm run build
npm run preview
```

The project is configured for automatic publishing to GitHub Pages. On every
push to the `main` branch, `.github/workflows/deploy.yml` installs dependencies,
checks TypeScript, generates the build, and publishes the `dist/` directory.

Before the first deployment, open **Settings → Pages** in the repository and
select **GitHub Actions** under **Build and deployment → Source**. A deployment
can also be started manually from the **Actions** tab.

The build uses the `/Liftbook-site/` base path, matching the repository's
current name. If the repository is renamed or starts using a custom domain,
update the `base` option in `vite.config.ts`.

The build has multiple pages and includes both the landing page and
`privacy-policy/index.html`, without requiring SPA fallback rules.

After deployment, the landing page and policy will be available at:

- `https://rabpaulo.github.io/Liftbook-site/`
- `https://rabpaulo.github.io/Liftbook-site/privacy-policy/`

Enter the second URL in the Play Console **Privacy policy** field.

The final host must use HTTPS and keep the policy at a public, active URL with
no login or geoblocking. The policy must not be editable by visitors and must
be HTML, not a PDF. After deployment, open the URL in a private window and
confirm that all text, icons, fonts, and links load without authentication.

The landing page contains no form, analytics, cookies, or pixels. The JavaScript
generated by Vite only renders the React interface in the browser. The hosting
provider may still retain its own technical logs; review and identify that
provider in the policy once hosting is selected.

The store copy respects Google Play's current limits: 30 characters for the
title, 80 for the short description, 4,000 for the full description, and 500
for release notes.

The screenshots came from the real app on a Samsung SM-G780F, without mock
data or overlaid promotional text. The system bars were removed and the
interface was framed on a black background at 1080 × 1920. The prepared order
is:

1. estimated 1RM progress chart;
2. searchable exercise library with categories;
3. cardio statistics by period;
4. bodyweight with weekly average, trend, and history.

The screenshots show real values stored on the device. Confirm that the owner
authorizes publishing those values before uploading them to Google Play.
